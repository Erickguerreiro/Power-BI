# Power-BI
O objetivo é apresentar uma explicação básica sobre o Power BI, voltada para pessoas que estão começando a utilizar a ferramenta. A ideia é ensinar, de forma simples e prática, como funciona o Power BI, como importar e organizar dados, criar visualizações e gráficos, utilizar os principais recursos da ferramenta e montar um dashboard básico. Ao final, o participante deverá ter uma visão geral do Power BI e saber como utilizar suas principais funcionalidades no dia a dia.

# Diretrizes 
As principais diretrizes definidas para o desenvolvimento do material foram apresentar o Power BI de forma simples, didática e acessível para pessoas que ainda não possuem conhecimento sobre a ferramenta.

A orientação foi focar nos conceitos básicos e nas principais funcionalidades do Power BI, mostrando passo a passo como utilizar a ferramenta, desde a importação e organização dos dados até a criação de gráficos, visualizações e dashboards.

Também foi definido que a explicação deveria utilizar uma linguagem clara e objetiva, evitando termos muito técnicos e priorizando exemplos práticos que facilitem o aprendizado. O objetivo é que, ao final do material, uma pessoa iniciante consiga compreender a lógica do Power BI e tenha autonomia para realizar suas primeiras análises e criar seus próprios relatórios.
